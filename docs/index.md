# Tennis Knowledge Base

A tennis knowledge base spanning Foundation, Advanced, and Elite technique and tactics, plus a dedicated Science Lab for the anatomy and biomechanics underneath the strokes.

## Sections

- **[Foundation](foundation/basics/index.md)** — strokes, grips, footwork, doubles patterns, and the core coaching guides.
- **[Advanced](advanced/basics/index.md)** — tactical patterns, scouting, in-match adaptation, and the neurological/biomechanical deep-dives underneath advanced play.
- **[Elite](elite/basics/index.md)** — for players who've outgrown copying pro technique and are building a personalized system.
- **[Science Lab](science-lab/index.md)** — anatomy and joint-by-joint biomechanics, independent of playing level.
- **[Players](players/index.md)** and **[System](system/index.md)** — supporting reference sections.

This site is under active construction — see the project repository for the full development plan and current status.
